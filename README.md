# cutest-picture-01

Image competition entry. `main.py` validates the stored picture (JPEG structure, dimensions and size limits) and copies it to the output. The picture held in this repo is "Bubble Trouble" — a baby fennec fox blowing an oversized pink bubblegum bubble — from the v4 build; the account's standing entry is the v3 picture. Python 3.13, standard library only.

Status: v3 standing entry, scored; results ~2026-11-27.

Note: the image files for this entry are not included in this repository because the upload channel used here is text-only.
